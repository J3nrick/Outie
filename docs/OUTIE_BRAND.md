# Outie — app identity

October 10, 2026. The user requested a witty name and an original app icon inspired by a pasted collection of colourful indie app icons. Outie is the selected creative direction: a short, playful name tied to heading out. Tagline: “Head out. Less left behind.”

The icon is a chunky ivory doorway with a winking face on a rich red background. Its open door links the character to departure preparation; the red aligns with the current app accents. A single silhouette, restrained ceramic depth and no text keep it recognisable at Home Screen sizes. The reference informed mood and boldness, not a copied logo.

The image was created with the built-in imagegen tool. The original is retained in `mobile/assets/images/outie-icon-source.png`; the opaque 1024 × 1024 shipping asset is `mobile/assets/images/outie-icon.png`. Only output sizing changed during asset preparation. iOS applies its own outer icon mask. Expo configuration uses this asset for the launcher and web favicon; the welcome screen displays it locally. Satoshi typography and Solar interface icons continue.

Outie is the current React Native display identity. Existing bundle/package identity, URL scheme, database and the separate SwiftUI DEPART reference stay in place for upgrade continuity. Expo regenerates the native iOS project as Outie. Historical DEPART briefs and verification reports remain historical. This creative naming pass does not establish trademark or store-name availability.

## Generation prompt

Create a production-ready original iOS app icon for Outie, a witty app that helps people check their essentials before heading out. Style direction: bold single silhouette, playful mascot, restrained tactile 3D polish like premium indie app icons. Full square 1024x1024 artwork, opaque, edge-to-edge rich scarlet red background with a very subtle red-to-ruby tonal shift. Center one warm ivory open doorway mascot: a chunky door frame with a slightly ajar door panel, rounded edges, a small simple cheeky winking face on the door panel (one black eye, one black wink and a subtle smile), tiny dark door handle. Doorway silhouette should be immediately clear and occupy about 65-70% of canvas, spacious outer margins. Slight 3/4 dimensional depth, soft ceramic feel, crisp contours, gentle highlights and contact shadow, strong contrast. A single unexpected playful tilt suggests it is about to head out. No letters, no words, no typography, no badges, no checkmark overlay, no multiple objects, no keys, no hands or limbs, no sparkles, no busy scenery. Do not draw an app tile border, do not round or cut off the outer square corners, no surrounding black canvas or device mockup. This must be a single complete square icon asset, not a grid of concepts. Original character; do not reproduce another app's logo.
